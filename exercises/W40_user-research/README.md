## Rules of the format
- Recruit people + write questions in advance. Start with a short introduction (who you are, what it's about, no wrong answers).
- Ask about **experiences** (stories), not opinions. Questions start with **how / what**, not *have you / is / was*.
- Ask about the **past**, not the future: "Tell me about the last time you…" instead of "What would you do if…".
- **Don't supply the answer** — no judgements or your own wording in the question.
- **Funnel:** 3–4 broad openers → 5–6 deeper questions → follow-ups in the moment.
- **Two-thirds rule:** the interviewee talks 2/3 of the time. Endure silence.
- Roles: one asks, one notes **word for word**. Explain nothing, defend nothing, don't pitch the concept.
- Ask how they'd judge success: "How would you have noticed that this really helped you?"
